# homebrew-claudoscope (retired)

Claudoscope is now in the official Homebrew cask repository. No tap needed:

```
brew install --cask claudoscope
```

This tap only carries a `tap_migrations.json` so installs made from it move to the
official cask on the next `brew upgrade`. You can remove it with
`brew untap cordwainersmith/claudoscope`.

Project: https://github.com/cordwainersmith/Claudoscope
